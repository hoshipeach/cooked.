# COOKED! brand assets

The approved production logo is `cooked-logo.png`. The interface uses that exact file and preserves its intrinsic proportions with `object-fit: contain`; it does not crop, redraw, recolour or reinterpret the artwork.

The locally bundled interface fonts are:

- `fonts/Fraunces-Variable.ttf` for expressive recipe titles, stage instructions and prominent editorial labels.
- `fonts/NunitoSans-Variable.ttf` for readable instructions, ingredients, quantities and controls.

Both typefaces are distributed under the SIL Open Font License. Their licence texts are stored alongside the font files. Fraunces and Nunito Sans were sourced from the official Google Fonts repository.

If the approved master is PNG rather than SVG, update only the `src` in `planner/index.html`; do not convert, trace or reinterpret the artwork.
